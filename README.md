# Habit Tracker — Трекер привычек

Веб-приложение для отслеживания ежедневных привычек. Разработано в рамках курса AI-разработки с использованием **GigaCode** (российский AI-ассистент от Сбера).

##  Возможности

- ✅ Добавление привычек (название от 3 символов)
- ✅ Отметка выполнения (чекбокс)
- ✅ Удаление привычек
- ✅ Счётчик выполненных привычек
- ✅ Прогресс-бар
- ✅ Сохранение в localStorage
- ✅ Адаптивный дизайн (мобильные + десктоп)
- ✅ Стиль Glassmorphism

## 🛠 Технологический стек

| Компонент | Технология |
|---|---|
| Язык | TypeScript 5.9 |
| UI | React 19.2 |
| Сборщик | Vite 8.3 |
| Стили | CSS (Glassmorphism) |
| Тесты | Vitest + React Testing Library |
| AI-ассистент | GigaCode |
